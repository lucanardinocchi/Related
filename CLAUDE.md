# Related

## Agent skills

### Issue tracker

GitHub Issues at [lucanardinocchi/Related](https://github.com/lucanardinocchi/Related) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical defaults: `needs-triage`, `needs-info`, `ready-for-agent`,
`ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context monorepo: `mobile` (Expo iOS), `web` (Next.js), `backend` (Supabase), `shared` (framework-agnostic domain layer). See `docs/agents/domain.md` and [ADR-0007](docs/adr/0007-split-web-mobile-frontends.md) for the web/mobile split.
